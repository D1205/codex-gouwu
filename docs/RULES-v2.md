# 开放零件建模规则 v2

本规则用于 `engineering-task/2` → `cad-plan/2`，版本为 `engineering-rules/2`。零件名称是需求标签，不是可执行类别白名单。可以直接描述法兰、轴、衬套、管件、垫圈、板、支架或其他零件；程序按建模特征判断如何执行。v1 任务和已发布文件继续使用原规则，不静默迁移。

## 任务与来源

- `family` 接受标识符形式的任意名称；`goal` 保存中文意图。新建使用 v2，已有 v1 的参数修改保持 v1。
- 参数采用动态 `snake_case` 名称，分别保存数值、单位、来源、确认状态。来源引用必须可追溯到用户原话或已发布基线。未知值保持 `null`；规则建议与推导不能自行当作用户确认。
- 单位为 `mm/cm/m/deg/count`。长度统一毫米，角度统一度，数量是正整数。角度、位置可以为零，位置可为负；不会把孔数或角度标成毫米。
- 所有记录的执行参数都必须用于建模特征。不能接受用户给了槽宽、实际却忽略槽的任务。
- 硬约束使用该参数的规范单位（mm、deg 或 count）。修改仍需上一发布版的 revision/hash；受保护值和旧文件保留。

## 通用特征

当前执行器处理 XY 平面剖面沿 +Z 的增料、切除，支持不同 Z 起点、盲深、圆周和线性阵列。剖面包括圆、中心矩形和闭合多边形。通过组合可形成圆盘、法兰、直轴/阶梯轴、套筒、环、等截面管、板件、支架及多边形隔套等；这些名称均不是枚举门槛。

每个特征的固定数据格式：

```json
{
  "id": "bolt_holes",
  "operation": "cut",
  "profile": {
    "kind": "circle",
    "center": [0, 0],
    "diameter": "hole_diameter",
    "size": [],
    "points": []
  },
  "start": 0,
  "depth": "thickness",
  "pattern": {
    "kind": "circular",
    "count": "hole_count",
    "radius": "bolt_circle_diameter/2",
    "angle_deg": 0,
    "step": [0, 0]
  }
}
```

圆的 `diameter` 必填，`size/points` 为空；矩形用 `size:[宽,高]`，`diameter:null`、`points:[]`；多边形用相对 `center` 的局部点，`diameter:null`、`size:[]`。无阵列时 `pattern:null`。圆周阵列绕 `profile.center` 布置，第一实例位于指定角度，随后按 `360/count` 均布；它复制剖面而不旋转剖面。线性阵列每次平移 `step`，radius 和 angle 为零。

尺寸字段只能使用有来源的参数与 `+ - * /`、括号构成表达式；原点可用零，半径/多边形关系可使用数值系数。不能将未确认的 100 mm 直接藏在剖面里。表达式按 AST 逐节点解析，无 `eval/exec`、属性访问或函数调用；相加减必须单位相容。

首个特征必须增料；起点非负、深度为正。自交轮廓、没有实际增减料效果、完全切空或最终成为不连接实体的计划不能执行。特征数、阵列数和实例数有本机计算预算，达到预算时要求拆分任务；不因零件名称拒绝需求。

## 计划与执行

`CADPlan/2` 同时保存原始 `feature_recipe`、数值化 `features`、参数值/单位及参数到特征路径的绑定。`parameter_values` 包含 mm/deg/count 规范值，`parameters_mm` 仅包含长度。历史字段 `hard_constraints_mm` 在 v2 中保存对应参数的规范值，应结合 `parameter_units` 解读。重新解析的数值特征或绑定不相同，计划即拒绝。上述内容、交付要求、容差和规则/技能版本均进入语义指纹。

SolidWorks 只执行本地已实现的建模操作，不接收模型生成的代码。仅连接已有实例，要求会话无打开文档；所有修订生成新文件。命名草图、完全定义状态、盲深与起点均在原生保存重开后回读，STEP 重新导入检查。

独立于 SolidWorks 的分层平面 CSG 计算预期体积和包络。圆采用 8192 边近似，体积比较相对容差为 `1e-5`，坐标按任务几何容差检查；这项近似用于数值核对，不改变原生圆。实现使用 Shapely/GEOS 的[平面集合运算](https://shapely.readthedocs.io/en/stable/manual.html)及[圆缓冲近似](https://shapely.readthedocs.io/en/stable/reference/shapely.buffer.html)。

STL、原生视图、映射和下载文件绑定同一修订与文件指纹。数值通过后仍为待审阅，明确登记看图结论后才发布。当前只证明几何建模与文件交付；强度、制造公差、标准规格及实际性能按具体需求另外验证。

## 如何处理尚未实现的建模步骤

输入入口接受任意零件描述。若需求包含当前执行器尚未实现的曲面、扫掠、螺纹或其他操作，必须保留原需求，明确指出缺少哪种操作或参数，不擅自简化，不要求用户将零件改名成底板/支架/盒体，也不声称所有工程零件已自动验证。
